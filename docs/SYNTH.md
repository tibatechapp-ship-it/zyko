# المُقترِح الحتمي — البرمجة بالبحث داخل النحو المغلق (الجولة 15، 2026-11-12)

هذه الوثيقة أرشيف الجولة 15: الطبقة التي تجيب سؤال المستخدم الحرفي —
**«هل يمكن لـ zyko أن يبرمج بلا ذكاء صناعي؟»** — بجدول لا بشعار،
وتكمل ثنائية الجولة 14: الحاكم يحكم سكونياً، والمُقترِح هنا يبحث وينفّذ.

## 1) الثنائية الكاملة

بعد 0.38.0 كان الحاكم الشكلي يحكم العقود المعلنة سكونياً بلا تنفيذ —
والنصف الآخر كان غائباً: من يكتب الكود؟ الجواب التقليدي (نموذج لغوي
سحابي) يكسر عقد zyko الحتمي. الجواب هنا: **المُقترِح الحتمي** —
`zyko.tools.synth` — يقرأ مهمة بعقود معلنة، يعدّد نحوًا مُغلقاً من
المرشحين بترتيب ثابت بالبايت، ينفّذ كل مرشح على نقاط المجال المعلن
في مساحة أسماء مبيّضة، ويُسلّم فائزه للحاكم للتحكيم الأخير:

```
عقد المهمة (spec.py) → نحو مُغلق (grammar.py) → بحث وتنفيذ مبيّض
                     → فائز → الحاكم الشكلي (0.38.0) → إيصال موقّع
```

بلا شبكة، بلا نموذج لغوي، بلا عشوائية — نفس المهمة نفس البرنامج
نفس الإيصال بالبايت.

## 2) عقد المهمة

```python
# zyko:task: ضاعف المدخل
# zyko:requires: x >= 0
# zyko:ensures: result * 2 == x
# zyko:domain: x = range(0, 8)
def double(x):
    raise NotImplementedError
```

القارئ (`spec.parse_task`) حكمه ثلاثي صادق مثل الحاكم تماماً:
سليم / مرفوض بدليل عربي (لا هيكلية، دالتان، `result` معاملاً،
معاملات متغيرة، مجال مشوّه أو مكرر أو لغير معامل، اسم خارج
المعاملات) / غير قابل للتحقق (لاحق غائب، معامل متعاقَد عليه بلا
مجال). المجالات: `name = range(a, b)` (السوالب مقبولة) أو
`name = [قيم حرفية]` — تُفرد لنقاط تنفيذ بسقف 64 نقطة بعيّنة
خطوة ثابتة.

## 3) النحو المغلق

المرشحون أشجار تعبير مبنية برمجياً لا نص حر — أصناف AST المسموحة
ثابت مجموعة، وأي مرشح يُفحص بنيوياً قبل التجميع كأنه أجنبي
(دفاع في العمق):

* **أوراق**: المعاملات بترتيب التوقيع + ثوابت مُحصودة من العقود
  نفسها (أرقام نص العقد بلا سقف، ونقاط المجال بحد |v| ≤ 20 و12
  قيمة) مع `0` و`1` دائماً.
* **كتل كل حجم بالترتيب**: `min`/`max`، المقارنات الست، الحسابي
  السبع، `and`/`or`، السلب، استدعاءات المسموح أحادية الوسيط
  (`abs` و`round` و`int` و`float` و`bool` و`len` و`sum` و`sorted`
  و`str`)، والثلاثي (ينشط عند سقف عقد ≥ 6).
* **حسورات معلنة**: سقف عقد التعبير (5 افتراضياً)، ميزانية مرشحين
  (200,000)، وشعاع كتلة (1,500 لكل كتلة) — فضاء مُعلن لا لا نهائي.

## 4) البحث والتحكيم

1. **المرحلة صفر — بذور موجّهة بالعقد**: كل `result == EXPR` ظاهرة
   في اللاحقات تعطي مرشحاً مباشراً (بلا `result` داخله، مفرزاً،
   بترتيب المشي الثابت). البذرة ليست حلّاً مجانياً: تُحكَم على النقاط
   مثل أي مرشح، وردُّها يكمل البحث، والإيصال يفصح `won_by`.
2. **المرحلة واحدة — التعداد النقي**: أصغر أولاً؛ لكل مرشح: فحص
   بنيوي، تجميع، ثم على كل نقطة مجال: المسبقات تُقصي (نقطة مخالفة
   للمسبق خارج القياس)، واللاحقات تحكم — أي استثناء أو شرط مخالف
   يُسقط المرشح فوراً.
3. **الفائز لا يخرج بلا حكم الحاكم**: المصدر يُعاد بناؤه بتوجيهاته
   الأصلية ويحاكم بـ`formal.check_source` — بلا قبول لا تسليم.

## 5) الأحكام الخمسة الصادقة

| الحكم | الخروج | المعنى الصادق |
|---|---|---|
| `synthesized` | 0 | فائز اجتاز كل النقاط وقبله الحاكم |
| `exhausted` | 1 | الفضاء المعلن كله استُنفد — **برهان غياب داخل الصنف** |
| `budget` | 1 | الميزانية قطعت البحث — قد يوجد فائز خارج ما فُحص |
| `invalid_spec` | 2 | عقد رديء — رفض القارئ بدليله |
| `unverifiable` | 2 | عقود بلا مجال أو فضاء بسقف غير مسموح |

الصدق عقد: البرهان داخل الصنف المعلن فقط (سقف العقد، الميزانية،
الشعاع، الثوابت — كلها في الإيصال)، وما خارجه يُعلن «غير مكتمل»
لا يُخفى.

## 7) الحدود الصادقة للصنف

ما يستطيعه المُقترِح اليوم: تعابير حتى 5 عقد — الحساب والمقارنات
والمنطق و`min`/`max` والاستدعاءات المسموحة والثلاثي (عند سقف أعلى)،
بمجالات عددية أو نصية، وبذور مباشرة لأي مساواة قابلة للتقييم.
ما لا يستطيعه (ويُعلن لا يُخفى): الحلقات والتعيينات والدوال
المركبة، والأهداف بلا عقود معلنة، والفضاء الأوسع من الميزانية —
هذه تحتاج موجات قادمة (صنف أوسع، نحو عبارات، بذور مركبة) أو عقلاً
حقيقياً خلف البوابات نفسها، والفاصل بين «برهان غياب» و«بحث غير
مكتمل» هو ما يجعل النتيجة قابلة للثقة في الحالتين.

## 8) العلل التي أصلحتها الموجة في جسدها

1. المرشحون المولَّدون بلا مواضع AST لم تُجمَّع أصلاً —
   `ast.fix_missing_locations` قبل التجميع.
2. فحص الأسماء البنيوي كان يخنق أسماء الدوال المسموحة — يُعفى اسم
   الدالة المُستدعاة وفحصها للـCall نفسه.
3. قارئ synth كان يقبل عقوداً تلمس أسماء خارج المعاملات — صار
   رفضاً بعقد الحاكم نفسه.
4. مجالات `range` بالسوالب كانت تُرفض من محلّل الحاكم — قُبلت
   (متوافق عكسياً: بصمة Eval-1000 `c3910dbb57acdee5…` (جُدِّدت مع جولة صدق المنصات — سلاسل النجاح صارت ثابتة البيئة)).
