# الدليل العام — repo-map بتوقيع الرموز والمختار المعجمي الحتمي (الموجة 21)

**التاريخ:** 2026-11-13 · **الإصدار:** 0.44.0 · **البروتوكول:** المختار المعجمي الحتمي على العينة الواسعة نفسها (44 حالة، psf/requests)

هذه الصفحة تعالج الفجوة الثالثة الموثقة في تقرير تقييم 0.43.0 (§7):
«الخريطة موجودة من جولة 11، والـ11 إخفاقاً اختيارياً بنمط الجوار
الدلالي هي علاجها المباشر: repo-map بتوقيع الرموز» — بالقياس لا
بالادعاء: وثيقة موقعة قابلة لإعادة التشغيل بأمر واحد، وكل رقم
حتمي بالبايت.

## 1. ما الذي تغيّر في الخريطة؟

خريطة جولة 11 كانت بايثونية حصراً ورموزَ مستوى أعلى حصراً: العقل
رأى «أسماء الشوارع» مع التوقيع الشكلي لا المعنى. الموجة 21 ترفع
الإشارة على أربعة محاور، بعقود جولة 11 كلها محفوظة (حتمية بالبايت،
صفر اعتماديات، فشل مفتوح، سقوف معلنة):

1. **توقيع دلالي**: سطر الوثيقة الأول لكل صنف ودالة يُلحق بالرمز —
   `class Session «إدارة جلسة HTTP بموصلات دائمة.»` — فيطابق العقل
   معنى التقرير مع معنى المقيم.
2. **أعضاء الأصناف**: دوال الأصناف باسمها الكامل
   `Session.resolve_redirects(url, *, max_hops)` — علة الجوار تُعالج
   من الجذر: ملف `sessions.py` الذي يسكنه `resolve_redirects` صار
   يُسمّى باسم محتواه لا باسمه فقط.
3. **عائلات لغات متعددة**: JS/TS وRust وGo وJava/Kotlin وC/C++ وRuby
   وPHP وShell بقوالب معلنة، ووثائق المستودع (Markdown عناوينها،
   YAML/JSON/TOML مفاتيحها الجذرية) — الخريطة تعمل على أي مشروع
   GitHub أو Hugging Face لا على بايثون فقط.
4. **عمل بلا git**: تنزيل Hugging Face أو أرشيف مُفكوك (لا `.git`)
   يُمشى على القرص بقائمة تجاهل معلنة `IGNORED_DIRS` — تعديل موثق
   لعقد جولة 11 («بلا git خريطة فارغة») لأن «الجاهزية في كل الظروف»
   لا تعرف المستودع المثالي.

سقوف معلنة جديدة: `MAX_SYMBOLS_PER_FILE = 24` و`MAX_DOC_CHARS = 72`
— الحجم محكوم لا منفلت.

## 2. العدّة — قيمة الخريطة بلا نموذج

الحكم على ترقية الخريطة لا يقبل الاستقراء، ونموذج حقيقي جديد هو
تشغيل الموجة 22 لا الموجة 21. فبنينا عدّة تقيس **قيمة المعلومة**
في الخريطة بلا أي ذكاء: `zyko.benchmarks.lexical_chooser` — مختار
معجمي حتمي بالبايت (معجم وتقاطعات حصراً، بلا شبكة بلا نموذج)،
يرتّب شجرة الاختيار مرتين لكل حالة: بخريطة v2 وبلا خريطة (مسارات
حصراً). درجة الملف: تقاطع رموز الاستعلام مع رموز مساره ورموز سطر
خريطته (وزن ×2 للطبقتين)، والأزواج المتساوية تُفروز بالمسار.

هذا حَدّ أدنى لمعلومات الخريطة — مختار لا يفهم المعنى — وأي عقل
فوقه يستثمر الرصيد نفسه. مرساة العقل الحقيقي (74.42% بخريطة جولة
11) تبقى المرجع الذي تُقاس عليه الموجة 22.

```bash
python3 scripts/measure_lexical_selection.py \
  --repo ~/.cache/zyko-swe/requests \
  --out benchmarks/results/lexmap_wide_2026-11-13.json
```

القراءة الصادقة:

- الخريطة توفر **مضاعفة أربعة** في إصابة أول-1 لمختار معجمي أعمى —
  قيمة المعلومة المضافة مقيسة لا مدّعاة.
- من الإخفاقات الـ11 المسماة للعقل الحقيقي (مرساة الموجة 20)، يصطاد
  المختار المعجمي بخريطة v2 ثلاثةً منها: `psf__requests-1537` و
  `psf__requests-3362` و`psf__requests-4356` — النمط الموثق (جوار
  دلالي) عولج جزئياً من الجذر: توقيع الرموز أحال ملف الجوار الشهير
  إلى صاحب العلة.
- الثمانية الباقية مشتركة مع العقل: تقارير لا تذكر أسماء الرموز
  إطلاقاً — عنوانها سياسة تحرير أعمق (الموجة 23) لا خريطة أدق.
- المختار المعجمي ليس العقل: رقمه حَدّ أدنى لا سقف — والرقم الذي
  يُعلن عن الموجة 21 هو قيمة المعلومة، والموجة 22 ستقارن إصابة
  العقل على العدّة نفسها.

## 4. إعادة التشغيل والعقد

- الوثيقة موقعة بسلسلة sha256 (`chain_hash`) وبلا أزمنة — إعادة
  التشغيل على نفس البيانات تعيد البصمة حرفياً (تحقق بتشغيلين
  متتاليين: بصمة واحدة `2ae28ab43ff67a5a`).
- المسارات الذهبية حصراً بلا محتوى رقعة — لا تصل للعقل ولا للمختار
  إلا بعد الجولة، عقد الموجة 20 محفوظ.
- كل سلوك جديد عليه اختبار مرساة في `tests/test_wave21_repomap_lexical.py`
  (22 اختباراً) ومرساة جولة 11 مرقّاة في `tests/test_round11_net_and_map.py`.
