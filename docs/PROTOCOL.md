# بروتوكول القياس القابل لإعادة التشغيل بايت-ببايت — الوثيقة العامة لzyko (جولة 12: الظهور)

**التاريخ:** 2026-11-12 · **الإصدار:** 0.36.0 · **المعرف:** `zyko-measurement-protocol/v1`

هذه الوثيقة هي العقد العام: **كل رقم نشرناه قابل لإعادة التشغيل على أي
جهاز بأمر موثق، وبصمة sha256 تحكم التطابق**. لا رقم يُستشهد به خارج
هذا البروتوكول — ولا رقم مقتبس من خارج جهاز التشغيل نفسه أصلًا.

## 1. الطبقات القابلة للقياس (الأمر + الوثيقة + البصمة)

| الطبقة | الأمر | الوثيقة/الوثيقة الناتجة | البصمة |
|---|---|---|---|
| الاختبارات والبوابات | `pytest -q --junitxml=/tmp/junit.xml` ثم `python scripts/check_readme_metrics.py --junit /tmp/junit.xml` | شارة README = الواقع لا الرغبة | junit مباشر |

وسلسلة sha256 حتمية — **الأزمنة خارج السلاسل دائمًا**.

## 3. الاكتشاف المركزي — الفصل بين الطبقتين مقاس لا ادعاء

1. **الطبقة الحتمية مستقرة بالبايت**: البروتوكول، والبوابات، والحرس،
   و`git apply`، وتشغيل الاختبارات، والإيصالات — نفس المدخلات تعطي
   نفس المخرجات والمحارف في التشغيلات الثلاثة كلها.
2. **طبقة النموذج عشوائية مقاسة**: حالة `3362` حُلّت **صارماً** في v2
   ولم تُحلّ في v3؛ وحالة `1963` حُلّت في v1/v2 وأفسدت 10 فحوص P2P في
   v3 — **التشغيل الواحد عيّنة لا حقيقة**، ولهذا يوّثق zyko كل محاولة
   لا أفضلها.
3. **الطبقة الميكانيكية تتحسن رتيباً**: الرقع المطبقة 4/6 → 4/6 → 5/6 —
   الحلقة والخريطة رفعتا جودة الصياغة الواصلة إلى `git apply` (الرفض
   بالحرس صفر في الجولات الثلاث).
4. **البوابات لم ترفض اقتراحاً واحداً في 18 محاولة عبر الجولات الثلاث** —
   العقل الافتراضي للنموذج نظيف من PII وأخطاء الاتجاه تحت بوابات zyko.

## 5. إعادة التشغيل الكاملة على أي جهاز

```bash
# 0) المستودع والإصدار
git clone https://github.com/tibatechapp-ship-it/zyko.git && cd zyko && pip install -e .
pytest -q                                   # 2,716 ناجح / 22 تخطيًا بيئيًا موثقًا
# 1) بيانات SWE-bench-Lite: benchmarks/data/swe_bench_lite_requests.json — في المستودع
git clone https://github.com/psf/requests.git /tmp/sb-repo
uv venv --python 3.9 /tmp/sb-venv39 && uv pip install --python /tmp/sb-venv39/bin/python httpbin gunicorn
/tmp/sb-venv39/bin/gunicorn --bind 127.0.0.1:8642 --workers 4 httpbin:app &
# 2) أي نقطة نموذج متوافقة مع OpenAI (جسر محلي أو سحابة):
ZYKO_QWEN_HOST=<نقطة_النهاية> ZYKO_QWEN_API_KEY=<مفتاحك> \
python3 scripts/run_swebench_lite.py --out benchmarks/results/swebench_lite_run.json
# ⇒ وثيقة جديدة بسلسلة sha256 خاصة بها — قارن بصمات لا ادعاءات
```
