01أربع ركائز تُميّز ZYKO

ليست بوابة أخرى — كل ركيزة تعالج فجوة حقيقية في أدوات التنسيق الموجودة اليوم.

توجيه قابل للتحقق

كل استجابة تحمل «إيصال توجيه»: ترتيب كامل للمرشحين بمكوّنات الدرجات والأوزان. أعد التحقق من أي قرار سابق دون اتصال.

جودة صادقة

درجات الجودة تأتي فقط من مقاييس مرجعية قابلة لإعادة الإنتاج ببذور ثابتة — لا من جداول تسويقية. بلا بيانات؟ 0.5 محايدة للجميع.

حوكمة شيفرة-كسياسة

سقف إنفاق يومي، حجب PII حتمي (بطاقات/إيميل/IBAN)، قوائم سماح للنماذج والأدوات، حدود معدل، وسجل تدقيق — في ملف YAML واحد.

MCP أولًا

ZYKO يستهلك خوادم MCP كأدوات لوكلائه، ويعرض نفسه كخادم MCP لأي مضيف — بروتوكول واحد يعمل في الاتجاهين.

02التثبيت على أي منصة

نواة Python خالصة (httpx + PyYAML فقط) — لا شيء يُترجم إلزامياً على أي منصة، بما فيها Termux.

$ pip install git+https://github.com/tibatechapp-ship-it/zyko.git

# first run — no keys, no network:
$ zyko ask "hello zyko" --demo --explain
$ zyko serve        # OpenAI-compatible gateway on :8787
PS> pip install git+https://github.com/tibatechapp-ship-it/zyko.git

PS> zyko ask "hello zyko" --demo --explain
PS> zyko doctor     # verifies paths, keys and kernel backend
$ pkg install -y git python
$ git clone https://github.com/tibatechapp-ship-it/zyko.git
$ cd zyko/android && bash install-termux.sh

# local inference on the phone — no cloud needed:
$ zyko ask "مرحبًا" --provider ollama
# Kivy UI + always-on gateway widget:
$ pkg install -y git python
$ git clone https://github.com/tibatechapp-ship-it/zyko.git
$ cd zyko/android && bash install-termux.sh --kivy

# packaging with Chaquopy/Buildozer → see android/README.md

كل أوامر CLI تعمل بلا مفاتيح عبر مزوّد العرض الحتمي المدمج — التوجيه والسياسات والإيصالات والبث كلها مسارات حقيقية.

03الحوكمة كملف واحد

سقف الإنفاق والحجب والسماح وحدود المعدل — ملف YAML واحد يُطبَّق على كل نداء، CLI ووكلاء وبوابة.

version: 1
name: strict
defaults:
  budget_usd_per_day: 2.0
  max_tokens_per_request: 2048
models:
  deny: ["*opus*"]
privacy:
  redact: [email, phone,
           credit_card, iban, ssn]
tools:
  deny: ["shell*"]
rate_limit:
  requests_per_minute: 30
zyko policy redact
$ zyko policy redact "card 4111 1111 1111 1111 mail bob@corp.com"
card [CREDIT_CARD] mail [EMAIL]

# deterministic PII redaction with Luhn check —
# enforced before any provider sees the prompt
