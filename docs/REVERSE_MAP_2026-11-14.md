## 2. ما نزل فعلاً في الموجة 26 (كود + اختبارات)

1. **`zyko.reviewer.repo_graph`** (زبدة Orbit): عقد = ملفات شجرة، حواف
   استيراد تُحل بالبايت، حواف اختبار (اختبار ⇒ مصدر يستورده)، جوار ملف
   واحد بأمر واحد — بلا شبكة، بلا git إلزامياً، حتمي بالبايت، الملف
   المجهول رفض مسمّى. **9 اختبارات مرساة**. البوابة التالية: تغذية
   مرحلة التخطيط بالجوار بدل قراءة الشجرة (توكن أقل ودقة أعلى على
   تعدد الملفات — ضعفنا المسمّى).
2. **`zyko.benchmarks.patch_audit`** (زبدة الطبقة الثابتة): ثماني قواعد
   مسمّاة على أسطر المضاف فقط (سر / eval / exec / صدفة / SQLi / except
   عارٍ / ابتلاع صامت / واسم معلّق)، درجات بأشد الإصابات، الأسطر
   المحذوفة ليست جريمة، أرقام أسطر مطلقة في الملف الهدف. **10 اختبارات
   مرساة**. مدخل لبوابة جودة الرقع قبل عدّها مطبقة.
3. **`zyko.utils.secret_scan` + `scripts/secret_scan.py`** (زبدة حماية
   Claude Code — درس تسعة عشر توكن صار عقداً): نمط قيمة السر واحد في
   المستودع تورّثه كل القواعد، الإثبات بصمة sha16 لا قيمة، علامة إعفاء
   `zyko:secret-ok` قابلة للبحث، وضع الفرق (المضاف فقط) ووضع الشجرة،
   **مربوطة إلزامياً في دورة النشر قبل الدفع**. **11 اختبار مرساة**.
4. **أدوات النشر الأربع صارت متتبعة** (`check_token` / `push-after-rotation`
   / `create_missing_releases` / `publish-release-cycle`) — كانت تسقط مع
   إعادة تدوير البيئة ثلاث مرات؛ الآن تُبنى مع المستودع ولا تسقط.
